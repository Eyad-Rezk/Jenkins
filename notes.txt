----------(JOBS)----------
- Group of steps "tasks" that are executed in a specific order to achieve a particular goal. 
- Each task can be a command, script, or program that performs a specific function.

---------(PLUGINS)----------
- Extensions that add additional functionality to a software application or platform.
- /var/lib/jenkins => plugins directory for Jenkins, where plugins are installed and managed.

----------(CREDENTIALS)----------
- Information used to verify the identity of a user or system, such as usernames, passwords, API keys, or certificates.
- Securely stores passwords, SSH keys, and API tokens

-----------(AGENT)----------
- A machine or environment that runs jobs and tasks in a continuous integration/continuous deployment (CI/CD) pipeline.
- worker node that executes the build and deployment tasks defined in the pipeline.
- agent types: 
   1-Static Agent: A "physical" dedicated machine that is always available to run jobs.
   2-Dynamic Agent(cloud): A temporary machine "vms , containers" that is provisioned on-demand to run jobs and is terminated after the job is completed. 


------------(PIPELINE)----------
- A set of automated processes that allow developers to build, test, and deploy their code in a continuous and efficient manner.
- It defines the sequence of steps that need to be executed to deliver a software application from source code to production.
- pipeline types:
   1-Declarative Pipeline: A more structured and opinionated syntax that provides a simpler way to define pipelines using a predefined set of keywords and blocks.
   2-Scripted Pipeline: A more flexible and expressive syntax that allows for greater customization and control over the pipeline's behavior using Groovy scripting language.

        stage('Test') {

                // 
            }
        }
        stage('Deploy') {

                // 
            }
        }
    }
    post {
        always {
            // 
        }
        success {
            // 
        }
        failure {
            // 
        }
    }
}

--------------------------------------(HOW TO SET UP JENKINS FOR GITHUB REPO)---------------

1- install jenins whatever you want in this demo i used ec2-ubuntu machine
2- create repo and push your project
3- create new jenkins job and enable these options:
                    - GitHub hook trigger for GITScm polling
                    - Poll SCM
                    - Pipeline script from SCM
                    - SCM => git
                    - add your repo and github credentials , github branch , path to jenkinsfile
4- in your repo go and create the Jenkinsfile and write your script
5- go to your github repo open settings => Webhooks => 
                    - add jenkins end point for ex: http://32.198.106.189:8080/github-webhook/
                    - select application/json
                    - Just the push event
6- and there you have it

--------------------------------------(HOW TO SET UP JENKINS NODE)---------------
1- launch your jenkins master and agent node  
2- open the ssh port on agent node so master can ssh to it
3- install openjdk (Open Java Development Kit) on agent node
4- open jenkins dashboard on the master node go to settings => node => new node
5- specify num of jobs , root dir , labels , nodes's ip , ssh credentials
6- after you finish go to agent node logs to check te status
7- don't forget to mention the agent node label in the pipeline like this:
pipeline {
    agent {
        node {
            label 'agent-01'
        }
    }
    stages {
        stage('Hello') {
            steps {
                echo 'Hello World'
            }
        }
    }
}
